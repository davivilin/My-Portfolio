Interactive 3D Solar System

> Project Overview

This is an accurate as possible small scale model of our solar system built using Three.js. Users can interact with the planets, view their orbits, and learn interesting facts about each celestial body.

The purpose of the project is to provide an engaging educational tool for teachers and students to explore the wonders of our solar system in a fun and interactive way without needing a high-end device. I built this with a friend as a submission for the 2025 Congressional App Challenge.

> Tech Stack

HTML/CSS JavaScript Three.js Node.js
