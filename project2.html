Code.org App Lab Projects

> Project Overview

I created both apps using Code.org's App Lab platform. Both are interactive applications designed to help students study and learn more effectively. The first app is for biology; more specifically, for the Biology EOC exam, which is an important exam in Florida.

The second app is for learning logical fallacies, which are common errors in reasoning that can undermine the logic of an argument. I created these apps in 9th grade to enhance my coding skills.
